SNS Uploader 개인정보처리방침

시행일: 2026년 10월 31일

SNS Uploader Studio는 대한민국에서 개인용 Windows 데스크톱 프로그램 SNS Uploader를 개발·운영합니다. 이 문서는 현재 버전 0.4.0의 확인된 기능을 기준으로 작성되었습니다.

제1조 처리 주체와 범위

SNS Uploader Studio는 현재 개인 사용 목적의 Windows 프로그램 SNS Uploader 0.4.0을 운영합니다. 자체 회원가입 서비스나 별도의 운영자 서버는 현재 구현되어 있지 않습니다. 이 방침은 프로그램이 로컬 컴퓨터에서 처리하거나 공식 Google·YouTube API에 전송하는 정보를 설명합니다.

제2조 처리하는 정보

Google OAuth 클라이언트 ID·시크릿, 접근 토큰·갱신 토큰, 토큰 만료 및 권한 정보, 채널 ID·이름, 재개 가능한 업로드 세션 주소를 처리합니다.

초안에는 사용자가 선택한 파일 경로, 제목, 설명, 해시태그와 플랫폼별 게시 문구가 저장됩니다. 업로드·예약 기록에는 원본 파일 경로, 채널 ID, 파일 해시·크기·수정 시각·형식, 게시 설정, 영상 ID, 예약 시각, 작업 상태와 오류 정보 등이 저장될 수 있습니다.

영상 원본은 사용자가 선택한 파일을 읽어 YouTube에 전송합니다. 별도의 업로드용 원본 파일 복제 기능은 확인되지 않았으나 앱 내부 캐시의 저장 내용 전체는 확인되지 않았습니다.

제3조 처리 목적

계정 인증과 연결 복원, 토큰 갱신, 채널 조회, 콘텐츠 업로드, 중복 업로드 방지, 중단된 전송 재개, 초안 복원, 예약 등록·관리, 오류 확인을 위해 정보를 처리합니다. 광고 타기팅이나 개인정보 판매를 목적으로 정보를 수집하지 않습니다.

제4조 저장 위치와 보호 방식

로컬 데이터는 Windows 사용자 데이터 폴더에 저장됩니다. YouTube 인증 정보와 재개 가능한 업로드 세션 주소는 Electron safeStorage를 사용하여 암호화된 youtube-secure.bin 파일에 저장됩니다. 암호화가 불가능할 때 평문으로 대체 저장하지 않습니다.

초안 draft.json, 업로드 기록 youtube-uploads.json, 예약 기록 youtube-schedules.json은 별도 앱 수준 암호화가 적용되지 않은 JSON 파일로 저장됩니다. 가져오기 전에 사용자가 보유한 원본 OAuth JSON 파일은 프로그램이 자동으로 암호화하거나 삭제하지 않습니다.

운영체제 및 Chromium 내부 캐시·저장소가 존재할 수 있으며 모든 캐시가 개인정보를 포함하지 않는다고 단정할 수 없습니다.

제5조 외부 서비스와 정보 전송

Google 로그인·동의 및 토큰 발급·갱신·철회를 위해 Google OAuth 서비스와 통신합니다. 앱 시작 시 기존 계정 연결을 복원하기 위해 채널 조회나 토큰 갱신 통신이 발생할 수 있습니다.

사용자가 업로드하거나 예약을 관리할 때 Google·YouTube 공식 API로 인증 정보, 영상 원본, 제목·설명·해시태그, 공개 범위, 아동용 여부, 영상 ID 및 예약 관련 정보를 전송합니다. OAuth 응답은 로컬 컴퓨터의 임시 콜백 서버에서 수신합니다.

현재 TikTok, Instagram, Threads, Facebook, Naver Blog에 대한 인증 또는 게시 API 전송 기능은 구현되어 있지 않습니다. YouTube 등 외부 플랫폼이 수신한 정보의 처리에는 각 플랫폼의 정책이 적용됩니다.

제6조 보관 기간과 삭제의 한계

현재 초안·업로드 이력·예약 기록에는 자동 만료 또는 정기 삭제 기능이 구현되어 있지 않아 로컬 데이터가 지속적으로 남을 수 있습니다.

YouTube 계정 연결 해제 시 저장된 토큰과 채널 연결 정보가 초기화되고 Google 권한 취소를 시도합니다. 네트워크 등의 문제로 권한 취소가 확인되지 않으면 Google 계정 설정에서 직접 권한을 철회해야 할 수 있습니다.

계정 연결 해제는 OAuth 클라이언트 설정, 업로드 세션 정보, 초안, 업로드·예약 기록, 원본 영상, 캐시 및 이미 게시된 YouTube 영상을 삭제하지 않습니다. 앱 제거만으로 로컬 사용자 데이터가 모두 삭제되는 것도 보장되지 않습니다.

로컬 기록 전체 삭제, 특정 채널 이력 삭제 및 캐시 일괄 삭제 기능은 현재 구현되어 있지 않습니다. 데이터 정리는 별도 수동 절차가 필요하며 플랫폼에 게시된 영상과 예약은 해당 플랫폼에서 별도로 관리해야 합니다.

현재 프로그램에는 데이터 삭제 요청 접수·처리 기능이나 원격 삭제 기능이 없으며, 삭제 요청을 받으면 실제 보관 위치와 기술적으로 가능한 처리 범위를 확인해 안내합니다. 관련 법령에서 보장하는 권리는 본 방침으로 제한되지 않습니다.

제8조 오류 정보와 안전 조치

프로그램에는 토큰을 직접 출력하는 전용 런타임 로그 기능이 확인되지 않았습니다. 다만 오류 메시지나 로컬 기록에는 영상 ID, 파일 경로, 채널 정보 등 식별 정보가 포함될 수 있습니다. 모든 로그와 내부 캐시에 개인정보가 전혀 남지 않는다고 보장하지 않습니다.

인증 정보 암호화는 Windows 사용자 환경의 보호 기능을 이용하며 같은 Windows 사용자 권한으로 실행되는 다른 프로그램으로부터 모든 정보를 완전히 보호하는 것은 아닙니다.
